## 2. Implement API endpoints for market day CRUD operations [pending]
### Dependencies: 8.1
### Description: Create RESTful API endpoints for creating, reading, updating, and deleting market days, including vendor participation management.
### Details:
Implementation steps:
1. Create controller for MarketDay with endpoints for:
   - GET /api/market-days (list all)
   - GET /api/market-days/{id} (get details)
   - POST /api/market-days (create new)
   - PUT /api/market-days/{id} (update existing)
   - DELETE /api/market-days/{id} (cancel/delete)
2. Create controller for VendorParticipation with endpoints for:
   - GET /api/market-days/{id}/vendors (list participants)
   - POST /api/market-days/{id}/vendors (add vendor)
   - DELETE /api/market-days/{id}/vendors/{vendor_id} (remove vendor)
   - PUT /api/market-days/{id}/vendors/{vendor_id} (update status)
3. Implement request validation
4. Add authentication and authorization checks
5. Create response serializers/transformers

Testing approach:
- API integration tests for each endpoint
- Authorization test cases
- Input validation test cases
